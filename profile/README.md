# Kronwerke

A community Minecraft server for streamers and their viewers. Every streamer brings a few people, everyone works toward the same goals, and the server unlocks new technology and magic when the community reaches them.

Season 2 runs in winter 2026/27 on NeoForge 1.21.1.

| Repository | What |
| --- | --- |
| [pack](https://github.com/kronwerke/pack) | The modpack, exported for Modrinth and CurseForge |
| [core](https://github.com/kronwerke/core) | The server mod: whitelist slots, community goals, staged progression |

Bugs and ideas go into the issues of the repository they belong to. Everything else happens on the Discord.
