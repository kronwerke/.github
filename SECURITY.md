# Security

If you find something that lets a player do what they should not be able to do (bypass the whitelist, grief through a protected area, crash the server from the client, escalate permissions), do not post it in a public issue or on Discord.

Send a direct message to the project lead on Discord, or open a private security advisory on the repository. You will get an answer within a few days. Once fixed, you are credited in the changelog unless you prefer not to be.
