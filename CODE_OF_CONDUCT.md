# Code of conduct

Kronwerke is a small community. The rules are short.

- Be decent. No harassment, no slurs, no drama carried over from somewhere else.
- Disagree with the idea, not the person.
- Keep other people's private details private. That includes streamers off stream.
- Report problems to the project lead on Discord. Reports are handled quietly.

Anyone who ignores this is removed from the server and the Discord. There is no appeals process for repeat offenders.
